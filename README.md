## What is adam?

adam provides building blocks for AI applications that join symbolic organization with reasoning driven by language models. The framework is intended for financial and risk-focused settings in which workflows, decisions, and generated results need to remain clearly coordinated and reproducible.

Its primary use cases include credit risk control, financial analysis and modeling, and collaboration between multiple agents. Integrations and concepts spanning LangGraph, Pydantic, Rust, and PROV help divide complicated AI processes into components that can be examined and managed individually.

## Core capabilities

- Apply neuro-symbolic patterns to structured reasoning and model-assisted decision processes
- Coordinate specialized agents through a multi-agent workflow architecture
- Execute repeatable paths with deterministic workflow orchestration
- Support credit risk control scenarios across institutional and fintech environments
- Build analytical and decision-oriented financial modeling pipelines
- Design agent workflows with LLM and LangGraph integration
- Manage typed inputs and structured outputs with Pydantic-oriented data handling
- Incorporate PROV-related provenance concepts into traceable workflow designs
